# LightPulse Monitor Server — 监控与巡检中心

LightPulse 监控中心服务端，采用**纯无状态水平扩展架构**，支持双机或多节点负载均衡部署。
负责接收 Agent 上报的主机指标与接口巡检记录，自动进行宕机即时感知、容量提前预警，并支持数据自动导出至 **VictoriaMetrics（原生 30 天自动滚动淘汰）** 与多通道机器人告警。

---

## 一、 快速部署（一键启动）

### 推荐：docker-compose 一键启动（Server + VictoriaMetrics + MySQL）

```bash
cd monitor-server
docker compose up -d
```

一键启动包含：
- **`monitor-server`**：监控控制台与 API 网关（端口 `8086`）
- **`victoriametrics`**：高性能时序存储（端口 `8428`，内置 `-retentionPeriod=30d` 自动物理清理 30 天前数据）
- **`mysql:8.0`**：元数据与规则存储（端口 `3307`）

启动后在浏览器打开：
👉 **http://localhost:8086** 即可访问现代化控制台大屏。

## 二、 核心架构特性

```
                       +-----------------------------------+
                       | 被监控目标机器群 (monitor-agent)   |
                       +-----------------+-----------------+
                                         |
                                         v (HTTP POST)
                       +-----------------------------------+
                       |    SLB / Nginx 负载均衡接入层      |
                       +--------+-----------------+--------+
                                |                 |
                                v                 v
                       +----------------+ +----------------+
                       | Monitor Srv A  | | Monitor Srv B  | (无状态多实例集群)
                       +--------+-------+ +--------+-------+
                                |                  |
            +-------------------+------------------+-------------------+
            |                                      |                   |
            v                                      v                   v
+-----------------------+              +-----------------------+ +---------------+
|    VictoriaMetrics    |              | 告警引擎 (AlertEngine)| | 关系型元数据  |
| (高压缩比时序引擎)    |              | (企微/钉钉/飞书)      | | (MySQL 8.0)   |
| -retentionPeriod=30d  |              +-----------------------+ +---------------+
+-----------------------+
```

### 1. 宕机秒级感知（解决“早上才知服务挂”的痛点）
- 内存状态机与数据库双重检测心跳：若任一主机或应用超过 60 秒无心跳，立刻触发 **P0 级【服务宕机/失联告警】**。
- 支持对接 **企业微信 / 钉钉 / 飞书 机器人 Webhook**。

### 2. 容量提前感知预警
- **内存预警**：物理内存占用持续 $\ge 90\%$ 触发告警，防止因突然 OOM 导致进程崩溃。
- **全磁盘挂载点巡检**：任一磁盘分区（如 `/` 或 `/data`）占用率 $\ge 88\%$ 触发预警，提前清理日志，避免磁盘打满造成业务拒绝写入。

### 3. VictoriaMetrics 时序存储自动淘汰
- 服务端以 Influx Line Protocol 格式批量导入 `http://victoriametrics:8428/write`。
- 多维标签体系：支持按 `app`、`host`、`env`、`mount` 进行毫秒级指标聚合。
- 内置内核级 30 天自动物理清理，免维护。

## 三、 控制台看板功能

在 Web 界面（`http://localhost:8086`）中可直接使用：
1. **🖥️ 主机性能与容量看板**：直观查看各服务器 CPU、物理内存余量、所有磁盘挂载点百分比进度条与最近上报时间。
2. **⚡ 接口巡检探活管理**：可视化新建、启停探针，查看接口延迟流水与 Token 自动续签状态。
3. **🚨 告警中心**：查看历史告警记录与一键确认。
4. **📊 APM 接口与慢 SQL 概览**：调用次数、平均耗时与错误率趋势。
